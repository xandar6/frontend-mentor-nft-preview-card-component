# Frontend Mentor - NFT Preview Card Component

This is a solution to the [NFT preview card component challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/nft-preview-card-component-SbdUL_w0U). The project is a small, responsive card component for an NFT preview, built with semantic HTML and modern CSS.

## Overview

### The challenge

Users should be able to:

- View the card layout across different screen sizes
- See hover and focus states for interactive elements

## My process

### Built with

- Semantic HTML5
- CSS custom properties

- CSS Grid
- Flexbox
- Mobile-friendly responsive layout
- Accessible focus states

### What I improved

The final version uses a clearer component structure with the `nft-card` block and BEM element classes such as `nft-card__image`, `nft-card__meta`, and `nft-card__creator`.

The card markup was also made more semantic by using an `article` for the card and a `footer` for the creator information. Decorative icons are hidden from screen readers, while the main artwork keeps useful alternative text.

### Key learnings

This project is a good example of how a small component can still benefit from thoughtful structure. BEM keeps the CSS organized, custom properties make the design tokens reusable, and semantic HTML makes the page easier to understand for browsers, screen readers, and future developers.

### Continued development

Useful areas to keep practicing after this project:

- Writing accessible alt text
- Choosing semantic HTML elements
- Structuring CSS with reusable naming patterns
- Testing hover and keyboard focus states
- Comparing a finished page against a provided design
